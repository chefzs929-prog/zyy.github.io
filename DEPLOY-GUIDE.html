目标：微信里能直接打开 · 反馈与分享数据安全留存

动手前先知道两件事

第一部分 · 上传到 GitHub（约 10 分钟）

1. 装 GitHub 客户端

1
下载 GitHub Desktop 访问 desktop.github.com，点 Download for macOS。 下载完双击打开，把图标拖进「应用程序」文件夹。
2
登录 打开 GitHub Desktop → 点 Sign in to GitHub.com → 会跳到浏览器， 点绿色的 Authorize desktop → 回到客户端就登录好了。

2. 把项目交给它管理

1
添加本地仓库 顶部菜单 File → Add local repository… 在弹出的路径框里填（或点 Choose 手动选到这个文件夹）： 
/Users/fz/WorkBuddy/2026-09-17-17-07-16
点 Add repository。左侧列表会出现这个项目。
这个文件夹我已经帮你初始化成 git 仓库了，所以不会报错。如果它提示 "This directory does not appear to be a Git repository" —— 赶紧停下来告诉我，说明有地方不对。

3. 发布到 GitHub

1
点右上角的 Publish repository 弹窗里有三个要填的：

Name（仓库名）

填 你的用户名.github.io，例如用户名是 zyyzhang 就填 zyyzhang.github.io。

用这个名字的好处是网址最短：https://你的用户名.github.io/，不用带一串斜杠路径。 填别的名字也行，网址会多一截 /仓库名/。

Description（描述）

随便写，或者留空。

Keep this code private ❗

把这个勾去掉。GitHub 免费账号只能给公开仓库发布网页，勾着的话后面开 Pages 会失败。

不用担心泄露 —— 代码里那串 key 是 Supabase 的公开 key，本来就是设计成写在网页里给所有人看的。 真正的密钥（sb_secret_）绝不会进这个仓库。

然后点 Publish repository，等进度条走完。

4. 打开网页托管

1
进仓库设置 在 GitHub Desktop 里点 Repository → View on GitHub， 浏览器会打开你的仓库页面。
2
找到 Pages 设置 仓库页面顶部有一排标签：Code / Issues / Pull requests / … / Settings。 点 Settings，再点左侧栏的 Pages。
3
开启 在 "Build and deployment" 下面：Source 选 Deploy from a branch； Branch 选 main，右边的文件夹选 / (root)，然后点 Save。
4
等 1~2 分钟，刷新页面 页面顶部会出现一条绿色提示：Your site is live at https://你的用户名.github.io/。 看到它就成功了。
注意：刚开完 Pages 那一两分钟访问可能报 404，这是正常的，GitHub 在后台构建。等一会儿再试。

5. 用微信实测（关键一步）

关掉 WiFi，用手机流量，把网址发到微信里点开。这是唯一真实的验证方式 —— 手机连 WiFi 可能走了代理，会掩盖问题。重点看三件事：
  • 首屏是不是很快就出来了（不再白屏等字体）
  • 滑块从下往上滑能不能翻页
  • 3D 机器人有没有正常出现
如果微信里显示「已停止访问该网页」 —— 那就是 github.io 这个共享域名被微信列进黑名单了 （不是你的内容违规）。这种情况只能靠买一个自己的域名解决：微信拦的是域名， 自有域名不在名单里，绑上去立刻就能开。域名几十块一年，解析到 GitHub Pages 不需要备案。 先测，真被拦了再买。

第二部分 · 接上数据存储

等第一部分验证通过，或者你想一次性做完，再执行这部分。做完反馈和分享就恢复了。

在此之前，你需要先拿到 Supabase 的两串值。之前复制失败那件事： 去 Project Settings → API Keys，优先找 sb_publishable_ 开头的那种 （只有 40 多个字符，比 eyJ 开头的 200 多字符好复制得多）。还是复制不了就直接截图发我。

建表 + 锁权限

左侧 SQL Editor → New query，粘贴执行：

-- 反馈表
CREATE TABLE feedbacks (
  id         BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  name       TEXT NOT NULL CHECK (length(name) <= 40 AND length(btrim(name)) > 0),
  rating     INTEGER NOT NULL CHECK (rating >= 1 AND rating <= 5),
  comment    TEXT NOT NULL CHECK (length(comment) <= 1000),
  profession TEXT,
  device     TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 分享推荐表
CREATE TABLE recos (
  id         BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  kind       TEXT NOT NULL CHECK (length(kind) <= 20 AND length(btrim(kind)) > 0),
  content    TEXT NOT NULL CHECK (length(content) <= 500 AND length(btrim(content)) > 0),
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 只允许写入，禁止读取/修改/删除
ALTER TABLE feedbacks ENABLE ROW LEVEL SECURITY;
GRANT INSERT ON public.feedbacks TO anon, authenticated;
CREATE POLICY feedbacks_insert_only ON feedbacks
  FOR INSERT TO anon, authenticated WITH CHECK (true);

ALTER TABLE recos ENABLE ROW LEVEL SECURITY;
GRANT INSERT ON public.recos TO anon, authenticated;
CREATE POLICY recos_insert_only ON recos
  FOR INSERT TO anon, authenticated WITH CHECK (true);

GRANT USAGE ON ALL SEQUENCES IN SCHEMA public TO anon, authenticated;

口令表与读取函数

-- 口令表：开启 RLS，但零授权零策略，客户端完全不可读
CREATE TABLE admin_secret (k TEXT PRIMARY KEY, pass_hash TEXT NOT NULL);
ALTER TABLE admin_secret ENABLE ROW LEVEL SECURITY;

-- 读函数：SECURITY DEFINER 绕过 RLS，口令不符直接抛错
CREATE OR REPLACE FUNCTION read_feedbacks(pass TEXT)
RETURNS SETOF feedbacks LANGUAGE plpgsql
SECURITY DEFINER SET search_path = public AS $fn$
BEGIN
  IF NOT EXISTS (SELECT 1 FROM admin_secret
                 WHERE k='owner' AND pass_hash = md5('wbfb::' || COALESCE(pass,'')))
  THEN RAISE EXCEPTION 'BAD_PASS' USING ERRCODE = '42501'; END IF;
  RETURN QUERY SELECT * FROM feedbacks ORDER BY created_at DESC;
END; $fn$;

CREATE OR REPLACE FUNCTION read_recos(pass TEXT)
RETURNS SETOF recos LANGUAGE plpgsql
SECURITY DEFINER SET search_path = public AS $fn$
BEGIN
  IF NOT EXISTS (SELECT 1 FROM admin_secret
                 WHERE k='owner' AND pass_hash = md5('wbfb::' || COALESCE(pass,'')))
  THEN RAISE EXCEPTION 'BAD_PASS' USING ERRCODE = '42501'; END IF;
  RETURN QUERY SELECT * FROM recos ORDER BY created_at DESC;
END; $fn$;

GRANT EXECUTE ON FUNCTION read_feedbacks(TEXT) TO anon, authenticated;
GRANT EXECUTE ON FUNCTION read_recos(TEXT) TO anon, authenticated;
注意顺序：口令表要先建、再单独执行一条 INSERT 把你的口令写进去。上面故意没带 INSERT， 因为里面要填你自己的口令 —— 单独跑这条，把引号里的内容换成你要用的口令： 
INSERT INTO admin_secret VALUES ('owner', md5('wbfb::' || '换成你的口令'));
口令只以哈希形式存进数据库，明文不落盘，也没人能从哈希反推出来。
